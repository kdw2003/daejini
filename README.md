# 대지니 (Daejini) — 경제·금융 챗봇

<img src="docs/icons/icon-192.png" width="72" alt="대지니 아이콘">

앱: https://daejini.streamlit.app · 휴대폰 앱: https://kdw2003.github.io/daejini/

한국어로 질문하면 주가, 환율, 경제 뉴스, 경제 용어를 알려주는 터미널 챗봇입니다.
**미국 주식 중심 투자 비서 웹 앱**도 들어 있습니다: 뉴스 요약·호재/악재 분류, 기업 분석, 산업 비교, 포트폴리오, 매매 참고 구간.

```
대지니: 안녕하세요, 경제 비서 대지니예요. (종료: '종료')
나: 삼성전자 주가 얼마야?
대지니: 삼성전자: 00,000.00 (▲ 0.00%)
나: PER 뜻이 뭐야
대지니: [PER] 주가수익비율. 주가를 주당순이익으로 나눈 값으로 ...
나: 종료
대지니: 다음에 또 봐요!
```

## 배경
2019년 고등학교 코딩동아리에서 라즈베리파이 기반 음성 비서 '대지니'를 만들었습니다.
"대진아 오늘 급식 알려줘"를 형태소 분석해 급식·학사일정을 알려주는 프로그램이었습니다.
이 프로젝트는 그 구조를 다시 설계하고, 관심 분야인 경제·금융으로 기능을 바꾼 버전입니다.

| | 2019 | 2026 |
|---|---|---|
| 형태소 분석 | Mecab (설치 복잡) | Kiwi (pip 설치) |
| 의도 분류 | if문 나열 | 키워드 점수 + 개체 인식 |
| 데이터 | 코드 안에 직접 작성 | JSON 파일로 분리 |
| 기능 | 급식, 학사일정 | 주가·지수, 환율, 뉴스, 용어 사전 |
| 테스트 | 없음 | pytest |

## 설치 및 실행
Python 3.10 이상이 필요합니다. 아래 명령은 모두 **프로젝트 최상위 폴더**(`main.py`가 있는 곳)에서 실행하세요.
`main.py`만 따로 복사해서 실행하면 `daejini` 패키지를 찾지 못해 `ModuleNotFoundError`가 납니다.

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux

pip install -r requirements-dev.txt   # 웹 앱 + 챗봇 + 테스트 (웹 앱만 쓰면 requirements.txt)
streamlit run app.py                  # 웹 앱
python main.py                        # 터미널 챗봇 ('종료', 'quit', 'exit'로 끝내기)
python -m pytest                      # 테스트 실행
```

- `requirements.txt`는 웹 앱에 필요한 패키지만, `requirements-dev.txt`는 거기에 챗봇용 형태소 분석기(Kiwi)와 pytest를 더한 것입니다.
- 주가·환율·뉴스 조회는 인터넷 연결이 필요합니다. 테스트는 네트워크 없이 돌아갑니다.
- 테스트는 `pytest` 대신 `python -m pytest`로 실행하세요. 그래야 현재 폴더가 import 경로에 들어가 `daejini` 패키지를 찾을 수 있습니다.

## 인터넷에 올리기 (Streamlit Community Cloud, 무료)
GitHub 저장소를 연결하면 `https://이름.streamlit.app` 주소로 어디서나 접속할 수 있습니다.

1. https://share.streamlit.io 에 **GitHub 계정으로 로그인**합니다.
2. **Create app** → **Deploy a public app from GitHub**을 고르고 아래처럼 넣습니다.
   - Repository: `kdw2003/daejini` · Branch: `main` · Main file path: `app.py`
   - App URL: 원하는 이름 (예: `daejini`)
3. **Advanced settings**에서 Python 버전을 3.12로 고르고, **Secrets**에 아래를 넣습니다.
   ```toml
   APP_PASSWORD = "직접 정한 비밀번호"
   # 아래는 있으면 넣기
   # ANTHROPIC_API_KEY = "sk-ant-..."
   # DART_API_KEY = "..."
   # SEC_USER_AGENT = "daejini 본인이메일"
   ```
4. **Deploy**를 누르면 몇 분 뒤 앱이 열립니다. 이후 GitHub에 올린 변경은 자동으로 반영됩니다.

알아 둘 점:
- **비밀번호**: `APP_PASSWORD`가 있으면 로그인 화면이 먼저 나옵니다. 로그인은 브라우저 탭마다 따로라서 새로고침하면 다시 입력합니다. 로컬에서 `.env`에 넣지 않으면 비밀번호 없이 열립니다.
- **데이터 초기화**: 무료 서버는 다시 시작되면 저장 공간이 지워집니다. 포트폴리오의 **백업 · 복원**으로 백업 파일을 받아 두고, 지워지면 복원하세요.
- **같은 데이터 공유**: 비밀번호를 아는 사람은 모두 같은 포트폴리오와 관심 키워드를 봅니다. 사용자별로 나누는 기능은 아직 없습니다.
- **잠자기**: 한동안 아무도 접속하지 않으면 앱이 잠들고, 다음 접속 때 깨우는 데 1분 정도 걸립니다.
- **시세 제한**: Yahoo Finance가 클라우드 서버의 요청을 일시적으로 막을 때가 있습니다. 그러면 잠시 뒤 다시 시도하세요.
- **휴대폰에서 앱처럼 쓰기**: 아래 '휴대폰 앱으로 쓰기'를 보세요.

- **시장 지수**: S&P 500, 나스닥, 다우존스, 필라델피아 반도체, 원/달러의 현재 값, 전일 대비 등락, 최근 한 달 미니 차트
- **오늘의 미국 증시 뉴스**: 최근 하루 미국 증시 관련 한국어 기사를 AI가 3줄로 요약합니다(Claude API 키 필요, 키가 없으면 최신 헤드라인 3개). 기사는 30분마다 새로 확인하고, 기사 목록이 바뀌었을 때만 다시 요약해 API 비용을 아낍니다.
- **내 포트폴리오**: 총 평가금액과 오늘 변동

- **더 알아보기**: 5개 기능으로 가는 바로가기

등락률은 일봉 데이터 대신 Yahoo Finance의 전일 종가로 계산합니다. 일봉 데이터에서 하루가 빠지는 경우가 있어서입니다.
화면 색과 설정은 `.streamlit/config.toml`에 있습니다. 빨강·파랑은 상승·하락에만 쓰고, 버튼 같은 강조색은 청록색입니다.

## 뉴스 브리핑
관심 키워드(종목, 산업, 경제 주제)를 등록하면 최근 뉴스를 모아서 키워드별 핵심을 3줄로 요약하고,
기사마다 호재·악재·중립과 영향 강도(1~3)를 붙여 줍니다.

```bash
copy .env.example .env          # Windows (macOS/Linux: cp .env.example .env)
# .env의 ANTHROPIC_API_KEY= 뒤에 Claude API 키 입력
streamlit run app.py            # 브라우저에서 http://localhost:8501 이 열림
```

1. 왼쪽에서 관심 키워드를 추가합니다. 예: 엔비디아, 테슬라, 미국 금리
2. 기간을 고르고 **뉴스 새로고침**을 누릅니다.
3. **한눈에 보기**에서 키워드별 호재·악재 수를 보고, 탭에서 요약과 기사 목록을 확인합니다. 분류와 영향 큰 순으로 걸러 볼 수 있습니다.

- 뉴스는 구글 뉴스 RSS 검색으로 모읍니다. API 키가 필요 없고, 같은 제목의 중복 기사는 한 번만 저장합니다.
- 분석은 Claude API(`claude-opus-5-5`)가 기사 **제목만** 보고 합니다. 제목만으로 방향을 알 수 없으면 중립으로 둡니다.
- API 키가 없으면 뉴스 수집과 목록 보기만 됩니다.
- 기사 목록이 지난 분석 때와 같으면 다시 분석하지 않아 API 비용을 아낍니다. 새로고침 한 번에 키워드당 API 호출은 최대 1번입니다.
- 키워드, 기사, 분석 결과는 `data/news.db`(SQLite)에 저장됩니다.
- AI 분석은 틀릴 수 있고 매수·매도 권유가 아닙니다.

## 기업 분석 · 산업 비교
`streamlit run app.py`로 연 웹 앱 위쪽 메뉴에서 고릅니다.

**기업 분석**
- 현재가, 시가총액, 52주 범위
- 핵심 지표 6개(PER, PBR, ROE, 영업이익률, 부채비율, 매출성장률)와 업종 중간값 비교
- 1년 주가와 20·60일 이동평균, 최근 4년 매출·영업이익·순이익
- 최근 뉴스(뉴스 브리핑과 연결, 버튼 하나로 관심 키워드에 추가)
- 최근 180일 SEC 공시: 연간·분기 보고서(10-K·10-Q), 주요 사항 보고(8-K) 등과 내부자 거래 신고 건수. 한국 종목은 DART 공시
- AI 브리핑: 지표·업종 중간값·뉴스 분류를 바탕으로 강점, 약점, 체크포인트 정리

**산업 비교**
- 빅테크, 반도체, 소프트웨어, 전기차·자동차, 금융, 헬스케어, 소비재, 에너지 8개 업종 미국 기업 36곳
- 지표 비교표, 지표별 가장 좋은 기업, 지표 하나를 골라 업종 중간값 선과 함께 막대 비교

지표 계산 방식:
- 시세와 재무제표는 Yahoo Finance(yfinance)에서 가져오며 API 키가 필요 없습니다.
- 모든 기업을 **현재 시가총액 ÷ 최근 회계연도 연간 실적(지배주주 기준)**으로 직접 계산해 같은 기준으로 비교합니다. 증권사 앱의 최근 4분기 기준 값과는 다를 수 있습니다.
- 업종 기준값은 평균이 아니라 **중간값**입니다. 자사주 매입으로 자기자본이 작아진 애플(ROE 150% 안팎)처럼 한 기업의 극단값이 업종 전체를 왜곡하지 않게 하기 위해서입니다.
- 미국 기업은 회계연도 마감 시점이 기업마다 달라(예: 애플 9월, 엔비디아 1월) 최근 연간 실적의 기준 시점이 조금씩 다릅니다.
- 금융사는 영업이익 항목이 없어 영업이익률을 계산하지 않고, 부채비율은 구조상 높게 나옵니다.
- SEC 공시는 키 없이 쓰지만 SEC가 연락처가 들어간 User-Agent를 요구합니다. `.env`의 `SEC_USER_AGENT`에 `앱이름 본인이메일` 형식으로 넣어 두세요(없으면 기본값 사용). CIK 목록은 처음 한 번 받아 `data/sec_ciks.json`에 저장합니다.
- 한국 종목 공시를 보려면 [DART 오픈API](https://opendart.fss.or.kr) 키를 `.env`의 `DART_API_KEY`에 넣습니다.
- 업종과 기업을 더하려면 `data/companies.json`에 `"기업명": "티커"`를 추가합니다. 포트폴리오 검색에 나오는 ETF 목록은 `data/etfs.json`에 있습니다.

## 포트폴리오
보유 종목의 수익률과 비중을 보고, 쏠림과 악재 뉴스를 점검합니다.

- **종목 추가**: 검색창에 이름이나 티커를 치면(예: 엔비디아, NVDA, SPY) 바로 고를 수 있습니다. 목록에 없는 미국 종목은 티커를, 한국 종목은 6자리 코드(예: 005930)를 입력하면 됩니다.
  - 평균단가 칸은 현재가로 미리 채워지니 실제로 산 가격으로 바꾸면 됩니다. 미국 주식은 소수점 수량도 넣을 수 있습니다.
  - 추가 전에 매수금액(원화 환산 포함)과 지금 기준 수익률을 미리 보여 줍니다. 이미 가진 종목이면 추가 매수 후 평균단가를 미리 계산해 보여 줍니다.
- **요약**: 총 평가금액(원화, 달러 환산), 총 손익, 오늘 변동, 적용한 원/달러 환율
- **보유 종목 카드**: 종목마다 현재가와 오늘 등락, 평가금액(달러 종목은 원화 환산도), 수익률, 비중 막대. 연필 버튼으로 수량·평균단가를 고치거나 지웁니다. 상승은 빨강, 하락은 파랑입니다.
- **환율**: 달러 종목은 현재 원/달러 환율로 원화 환산해 합계와 비중을 냅니다. 매수 당시 환율은 기록하지 않아 환차익·환차손은 포함하지 않습니다.
- **차트**: 종목별·업종별 비중, 종목별 수익률(탭으로 전환)
- **점검**: 아래 기준에 걸리면 알려 줍니다. 기준은 `daejini/portfolio/valuation.py` 맨 위에서 바꿀 수 있습니다.
  - 한 종목 비중 30% 이상, 한 업종 비중 50% 이상
  - 평균단가 대비 -10% 이하인 종목
  - 최근 3일 뉴스 중 영향 2 이상인 악재 (**보유 종목 뉴스 확인** 버튼으로 수집·분석, Claude API 키 필요)
- 처음에는 **예시 포트폴리오로 체험하기**로 현재가 기준 가상 단가의 예시 종목을 넣어 볼 수 있습니다.
- 시세는 10분마다 새로 가져오며 실시간이 아닙니다. 보유 종목은 `data/news.db`의 `holdings` 테이블에 저장됩니다.

## 매매 참고 구간
기술적 지표로 지금 차트 상태와 지지·저항 구간을 보여주고, 전략들이 과거에 실제로 통했는지 검증합니다.
참고용이며 매수·매도 권유가 아닙니다.

**지금 차트 상태**: 이동평균 배열(정배열·역배열), RSI(과매수·과매도), 볼린저 밴드 위치, MACD를 쉬운 말로 보여줍니다.

**참고 구간** (최근 120거래일 기준)
- 지지선·저항선: 앞뒤 5일 중 가장 낮은 저점·가장 높은 고점 가운데 현재가 바로 아래·위 가격
- 관심 구간: 지지선 ± 하루 평균 변동폭(ATR)의 절반 / 경계 구간: 저항선 ± ATR의 절반. 두 구간이 겹치면 중간 가격에서 나눕니다.
- 손절 참고선: 지지선 - ATR × 1.5
- 6개월 캔들 차트에 이동평균, 볼린저 밴드, 구간을 함께 그립니다.

**과거 검증 (백테스트)**
| 전략 | 규칙 |
|---|---|
| 이동평균 교차 | 20일 이동평균이 60일 위면 보유, 아래면 매도 |
| RSI 역추세 | RSI 30 이하 매수, 70 이상 매도 |
| 볼린저 반등 | 종가가 하단 아래면 매수, 중심선 위면 매도 |
| 지지 구간 매수 | 관심 구간에서 매수, 경계 구간 도달이나 손절 참고선 이탈 시 매도 |

- 모든 전략을 **단순 보유**(처음에 사서 끝까지 들고 있기)와 비교합니다. 총수익률, 연환산 수익률, 최대낙폭, 거래 수, 승률, 보유 비율을 보여줍니다.
- 신호는 그날 종가까지의 데이터로만 정하고 **다음 날 시가**에 거래합니다. 미래 데이터가 섞이지 않는지 테스트로 확인합니다.
- 비용 기본값: 미국 주식은 수수료 0.10%(매수·매도 각각)·세금 없음, 한국 주식은 수수료 0.015%·증권거래세 0.20%. 화면에서 바꿀 수 있습니다. 환전 수수료, 양도소득세, 호가 차이(슬리피지), 배당은 반영하지 않습니다.
- 기간은 1·3·5년 중 고릅니다. 지표 계산에 120거래일이 필요해 5년을 고르면 약 반년 늦게 시작합니다.
- AI 해설: 지표와 백테스트 결과를 초보자도 이해할 수 있게 풀어 줍니다(Claude API 키 필요).

## 할 수 있는 질문

| 의도 | 예시 질문 | 동작 |
|---|---|---|
| 주가·지수 | "삼성전자 주가 얼마야?", "오늘 코스피 어때" | 최근 종가와 전일 대비 등락률 (종목이 없으면 코스피) |
| 환율 | "달러 환율 알려줘", "엔화 얼마야" | 원화 기준 환율과 등락률 (통화가 없으면 달러) |
| 뉴스 | "경제 뉴스 보여줘" | 한국경제·매일경제 RSS 헤드라인 각 3개 |
| 용어 사전 | "PER 뜻이 뭐야", "기준금리가 뭐야?" | `data/glossary.json`에 있는 설명 |
| 도움말 | "도움말" | 사용 예시 안내 |

한 문장에 여러 개를 넣어도 됩니다. 예: "애플이랑 엔비디아 주가".

**지원 목록** (`data/` 폴더의 JSON 파일에서 관리)
- 종목·지수: 코스피, 코스닥, 나스닥, S&P500, 삼성전자, SK하이닉스, 현대차, 네이버, 카카오, 애플, 엔비디아, 테슬라
- 통화: 달러, 엔화, 유로, 위안
- 용어: 기준금리, PER, PBR, ROE, 인플레이션, 스태그플레이션, 양적완화, 국채, 경상수지, GDP, CPI, 배당, 공매도, ETF

## 동작 방식
```
입력 문장
  → nlp.tokenize      Kiwi로 형태소 분석
  → router.parse      ① 의도별 키워드가 형태소에 몇 개 있는지 점수 계산
                      ② 종목·통화·용어 이름을 찾아 해당 의도에 가산점(+2)
                      ③ 최고 점수 의도 선택 (0점이면 unknown)
  → bot.reply         의도에 맞는 handler 호출
  → 응답 문장
```

- 개체 인식은 띄어쓰기를 없애고 대문자로 맞춘 뒤 찾으므로 "s&p 500"도 "S&P500"으로 인식합니다.
- 이름이 긴 개체부터 찾아서 짧은 이름이 중복으로 잡히지 않게 합니다.
- "뭐"는 일상 대화에도 많이 쓰여서, 용어 사전에 있는 단어가 함께 나올 때만 용어 질문으로 봅니다. ("오늘 저녁 뭐 먹지" → unknown)

## 데이터 추가하기
코드를 고치지 않고 JSON 파일만 수정하면 됩니다.

| 파일 | 형식 | 예시 |
|---|---|---|
| `data/tickers.json` | 이름 → [Yahoo Finance](https://finance.yahoo.com) 티커 | `"LG에너지솔루션": "373220.KS"` |
| `data/currencies.json` | 이름 → 환율 티커 | `"파운드": "GBPKRW=X"` |
| `data/glossary.json` | 용어 → 설명 | `"PSR": "주가매출비율. ..."` |
| `data/intents.json` | 의도 → 키워드 목록 | `"news": ["뉴스", "속보", ...]` |

한국 종목 티커는 KOSPI는 `종목코드.KS`, KOSDAQ은 `종목코드.KQ` 형식입니다.
새 질문 표현을 넣었다면 `tests/test_router.py`에 예시를 추가해 두면 좋습니다.

## 참고 및 한계
- 시세는 yfinance(Yahoo Finance)에서 가져오며 실시간이 아니라 지연된 값일 수 있습니다. 조회에 실패하면 "지금은 시세를 가져올 수 없어요."라고 답합니다.
- 언론사 RSS 주소는 바뀔 수 있습니다. 뉴스가 안 나오면 `daejini/handlers/news.py`의 `FEEDS`를 확인하세요.
- 투자 판단용이 아닌 학습·개인 프로젝트입니다.
